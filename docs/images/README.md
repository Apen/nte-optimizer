# Documentation screenshots

This directory contains the curated English screenshots used by the public
documentation:

- `application-overview.png`: selected cartridge, console grid, and modules;
- `build-search-results.png`: search configuration, ranking, and projected stats;
- `characters-priority.png`: imported roster and equipment priority;
- `guided-import.png`: guided scan and latest import summary;
- `cartridges-inventory.png`: cartridge inventory and filters;
- `modules-inventory.png`: module inventory and filters;
- `arcs-inventory.png`: Arc inventory and ownership;
- `resources-inventory.png`: decoded resources and quantities;
- `damage-analysis.png`: current and projected damage by action.

Before committing a screenshot:

- crop or mask account identifiers and unrelated desktop content;
- avoid exposing raw capture paths, user names, or local directory names;
- use representative test data when possible;
- keep a consistent application window size and language;
- optimize the image without making text unreadable;
- update every documentation reference if a screenshot is renamed.
