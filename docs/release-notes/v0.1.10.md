# NTE Optimizer v0.1.10

## Highlights

- Add game data and recommended profiles for BlackBird (character ID 1042) and Akane (character ID 1057), with updated character portraits.
- Refresh character stats, Arc and equipment catalogs, damage data, localized descriptions, and recommendations. Add Prism and Twinbirds Arc data.
- Improve scanner preflight checks and privacy-safe diagnostics, prevent concurrent scans, and add an explicit Pktmon recovery action. The desktop app stays unelevated; recovery elevates only the scanner helper and stops system-wide Pktmon collection.
- Keep packaging available while a portable app is running by writing the new package to a separate directory.

## Decoder compatibility

This release updates game catalogs and scanner reliability; it does not change the network record parser. BlackBird is included in the character catalog, but it appears in an account export only when the game sends a BlackBird character record during capture and that record matches the supported format. If it is absent after a complete login scan, retain the failed capture and diagnostic log for protocol analysis.
