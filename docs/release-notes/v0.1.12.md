# NTE Optimizer v0.1.12

## Cartridge upgrade simulation

- Evaluate owned cartridges using their main stat at level 20, including cartridges that have not been upgraded yet.
- Enable or disable the simulation from the optimizer configuration; it is enabled by default in the desktop app.
- Include projected main stats in cartridge selection, ranking, final stats, goals, and estimated damage.
- Clearly identify simulated results and display the actual and target levels on cartridges that need upgrading.
- Preserve the equipped build's actual stats for comparison and keep the imported inventory unchanged.
- Keep existing substats without predicting future rolls. Projection uses the item's quality-specific game data.

## Validation

- Add regression coverage for quality-specific projections, unchanged inventory and substats, missing game data, and cartridge selection with actual versus simulated stats.
